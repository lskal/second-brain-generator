# Mesh Component Separation

Use Split or Separate when an imported mesh already contains distinct shells or components. This preserves their existing geometry and allows unwanted components to be removed without introducing a new cutting plane.

Use [[plane-cut]] instead when the desired separation does not already exist in the mesh.
