# Bambu Studio

Bambu Studio is a slicer used to prepare models for FDM printing. It supports print-process presets as well as limited mesh-preparation operations before slicing.

Use [[plane-cut]] for simple planar model changes and [[mesh-component-separation]] for meshes that already contain separate components. Use [[process-presets]] to select a configuration that matches the print's required balance of speed, appearance, and functional strength.
