# Cutting a Model in Bambu Studio

## Summary

Bambu Studio can make simple planar mesh edits directly in the slicer. [[plane-cut]] is the appropriate operation for removing a section, shortening a model, or creating two printable pieces. For meshes containing already-separated shells, [[mesh-component-separation]] avoids an unnecessary cut.

## Practical guidance

1. Select the imported model and open the mesh tools.
2. Position and rotate Plane Cut where the model should be divided.
3. Keep the upper side, lower side, or both resulting objects according to the intended outcome.
4. Use an external modeling application for non-planar or detailed geometry changes.
